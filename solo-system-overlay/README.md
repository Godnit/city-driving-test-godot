# نظام التدريب العائم — Prototype 0.1

تطبيق Android أصلي وخفيف يعرض نافذة مهمة عائمة في الوقت المحدد فوق التطبيقات.

## الوظائف الحالية

- يدعم Android 8.0 (API 26) وما بعده.
- تحديد اسم المهمة ووقت ظهورها.
- طلب إذن الظهور فوق التطبيقات.
- زر تجربة فورية.
- شاشة نظام أصلية مستوحاة من أجواء ألعاب الارتقاء، من دون نسخ أصول أو شعارات الأنمي.
- عداد خمس دقائق لقبول المهمة.
- وضع عقوبة بصري آمن لمدة دقيقة عند انتهاء العداد.
- نافذة قابلة للسحب رأسيًا.
- لا توجد مكتبات خارجية أو صور كبيرة.

## البناء

```bash
gradle :app:assembleRelease
```

المسار الناتج:

`app/build/outputs/apk/release/app-release.apk`

> هذه نسخة تجريبية موقعة بمفتاح debug لتسهيل التثبيت المباشر، وليست إصدار متجر نهائيًا.
