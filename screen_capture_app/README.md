# QuickScreenshot

تطبيق أندرويد خفيف لالتقاط الشاشة من زر دائم في الإشعارات.

## الاستخدام
1. افتح التطبيق واضغط «تفعيل زر الالتقاط».
2. وافق على نافذة أندرويد الخاصة بالتقاط الشاشة.
3. افتح الإشعارات واضغط «التقاط».
4. التطبيق يغلق لوحة الإشعارات، ينتظر 600ms، ثم يلتقط الشاشة ويحفظ الصورة.

على Android 8/9 تُحفظ الصور في `Pictures/QuickScreenshot` عند توفر إذن التخزين.
